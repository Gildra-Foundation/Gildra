# DataTest

Тестовый импортёр данных World of Warcraft для Gildra. Репозиторий проверяет схему импорта до переноса исправлений в основной проект.

## Что исправлено

- Дерево талантов идентифицируется по `specId`, а не по общему для класса `traitTreeId`. Поэтому Raidbots даёт 40 деревьев специализаций, а не 13 перезаписывающих друг друга записей.
- Каждый entry таланта сохраняется отдельной сущностью `talent`; повторяющиеся классовые таланты объединяют список появлений в специализациях.
- Полный JSON дерева Raidbots сохраняется в payload без потери узлов, связей и hero-talents.
- Для карточки дерева добавляется доступная иконка.
- Описания предметов из `ItemSparse.Description_lang` обновляются только в локализации текущей версии. Payload Raidbots и его иконка не заменяются.

> `Description_lang` — официальное текстовое описание из DB2, но это не полностью отрендеренный игровой tooltip со всеми вычисляемыми статами и эффектами.

## Команды

Ничего не записать, только скачать и проверить данные:

```powershell
go run ./cmd/datatest inspect-talents
go run ./cmd/datatest apply-talents
go run ./cmd/datatest enrich-items -build 12.1.0.69404 -limit 100
```

Запись включается только явным флагом `-confirm`:

```powershell
$env:DATABASE_URL = 'postgres://...'
go run ./cmd/datatest apply-talents -confirm
go run ./cmd/datatest enrich-items -build 12.1.0.69404 -confirm
```

Перед `-confirm` нужна актуальная резервная копия PostgreSQL. Обе операции используют транзакции; ошибочная операция откатывается целиком.
