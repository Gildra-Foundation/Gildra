# Open Graph card fonts

Static TTF instances for `lib/og/atlasOg.tsx` (Satori reads TTF/OTF/WOFF, not the WOFF2 that next/font serves):

- `alegreya-500.ttf` — Alegreya Medium, Juan Pablo del Peral / Huerta Tipográfica, SIL Open Font License 1.1 (Google Fonts).
- `inter-400.ttf`, `inter-600.ttf` — Inter Regular / SemiBold, Rasmus Andersson, SIL Open Font License 1.1 (Google Fonts).

Downloaded from fonts.gstatic.com on 2026-10-12. They are only read on the server when the cards are rendered (at build time).
