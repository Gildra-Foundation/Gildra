# Задача / передача работы

## Цель
Конкретное изменение и ожидаемое поведение.

## Основа
Ветка, исходный commit, связанные документы и принятые решения.

## Область изменений
Файлы, зависимости и ограничения. Какие чужие изменения обнаружены.

## План и критерии готовности
- [ ] Реализация соответствует цели и `brand.md` / `design.md`.
- [ ] Выполнены необходимые проверки EN/RU и состояний данных.
- [ ] Для интерфейса проверены мобильный и широкий экраны.
- [ ] Просмотрен полный diff, исключены секреты и временные артефакты.

## Проверки
Команда, результат, ограничения. Для пропущенных проверок — причина.

## Результат
Изменённые файлы, commit, branch, push и deploy отдельно.

## Продолжение
Нерешённые вопросы и конкретное следующее действие.
