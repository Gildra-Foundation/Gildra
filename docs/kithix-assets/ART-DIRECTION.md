# Kith’ix material kit

The current raid kit uses dark wine chitin, broad crimson lobes, coral nodules and coiled tendrils. Large asymmetric organic forms replace the earlier basalt-and-bronze frame. See [ORGANIC-ASSETS.md](ORGANIC-ASSETS.md) for native sources, proofs and measured geometry.

The scene now uses the original raid loading screen, at the user’s explicit request, rather than the earlier generated interpretation. Transparent outer padding is cropped; the original colors and detail are retained. It is decorative artwork, not an encounter map or a boss portrait.

Complete visible hub kit: scene with responsive exports, picture frame, nine-slice panel, nine-slice button, root ornament. The overview uses the same scene, panel and button. Navigation reads the artwork from the raid data. No extra mechanics, skill icons or boss portraits are inferred.

Native candidates, exact prompts, QA and proofs: `/home/debian/gildra-kithix-art-20261104/asset-sources/`. Public SOURCE files and manifests record selected native hashes and final geometry. Original alpha is retained; no retouching or upscaling. The loading-screen exports use the 2990×1148 inner artwork: desktop2400×921, small768×295 and centered mobile600×900, without upscaling. Scene provenance and hashes are recorded separately in the scenes SOURCE and manifest.
