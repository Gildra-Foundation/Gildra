## Граница проверки и следующий шаг

Сведения в JSON — краткий пересказ источников, а не проверка клиентом WoW. Источники могут расходиться: например Icy Veins называет лужу Mchimba Burning Ground, Method/Wowhead отличают cast Burn Corruption и лужу; JSON не объявляет название cast ошибочным.

Текущие произвольные x/y, количество врагов, силы и времена не имеют связи с конкретными clone ID. Проверенные правила боя не доказывают существование указанной комбинации мобов в одной точке. Следующий шаг: зафиксировать версию MDT и маршрут автора, сопоставить `enemy ID + clone ID + group + sublevel` с картой, затем показать путь танка, места сбора и рассчитанный count. До этого не отображать точные проценты как проверенные.

Проверки: JSON читается стандартным парсером; все facts.source входят в sources; RU/EN заполнены; изменены только два разрешённых файла этого агента. Память обновляет root.
