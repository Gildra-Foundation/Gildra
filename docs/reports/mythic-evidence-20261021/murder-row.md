# Murder Row — проверка 2026-10-21

Проверен исходник `apps/web/components/wow/mythic/dungeonRoutes.ts`, блок `murderRow`. Создан RU/EN evidence JSON; общие исходники не менялись. Live, commit и push не выполнялись.

Источники и ссылки каждого факта находятся в `apps/web/data/wow/mythic-reviews/murder-row.json`. [Blizzard подтверждает сезон](https://news.blizzard.com/en-us/article/24294369/midnight-season-2-is-now-live). [Официальный hotfix](https://worldofwarcraft.blizzard.com/en-us/news/24307310/hotfixes-16-de-octubre-de-2026) от 16 октября найден через индекс поиска: непосредственное открытие страницы вернуло 403. Это ограничение явно записано.

[Method / Tactyks](https://www.method.gg/guides/dungeons/murder-row) открывается целиком, дата статьи 18 августа; [Icy Veins / Petko](https://www.icy-veins.com/wow/murder-row-dungeon-guide) — 12 октября. Это авторские игровые рекомендации, не доказательство прохождения конкретного маршрута нашей группой. Четыре имени боссов черновика совпадают с гайдами.

Ключевые дефекты исходника: босс 1 лишён важного дополнительного противника, не показаны промежуточные события, обычным магам приписаны образы без подтверждения. «Склад» ошибочно представлен как область без установленных NPC. Некоторые финальные пулы используют призывных существ и голословно обещают достижение цели сил. Назначения ShadowNova и прочих имён не связаны с реальной группой.

[Реальный raw MDT](https://raw.githubusercontent.com/Nnoggie/MythicDungeonTools/refs/heads/master/Midnight/MurderRow.lua) содержит NPC ID, клоны, группы, координаты и counts. Поисковый сниппет GitHub показывал старую заглушку; он отвергнут после открытия актуального файла. У Furious Vilefiend ID 234799 count=0; у боссов также count=0. Найденный порог 655 нельзя подменять суммой произвольных процентов.

Текущие x/y в Gildra не сопоставлены с системой координат текстуры MDT, поэтому не подтверждены как маршрут. [Method предлагает MDT-импорт](https://wago.io/mWO70E5hA), но он не декодирован в этой проверке. Следующий шаг: зафиксировать ревизию MDT, импортировать pull membership, сопоставить текстуру и координаты, пересчитать силы по NPC ID и проверить проходимость/переходы. До этого маршрут остаётся draft.

Проверка результата: JSON синтаксически разобран; каждый факт имеет URL из реестра sources. Игровой прогон и геометрия пуллов не проверялись.
