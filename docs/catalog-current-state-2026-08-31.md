снимка. Он описывает фактически доступные данные и не заменяет quality-gate:
наличие строки DB2 само по себе не означает, что у записи есть описание,
иконка, tooltip или подтверждённая связь.

## Что блокирует production-ready

1. Для текущего owner-approved режима deploy проверяет `dataReady`, но
   публикация внешнего API остаётся закрытой политикой источников.
2. В media cache остаются удалённые и повторно обрабатываемые ассеты; после
   следующего образа API кэшировщик использует и числовые FileDataID.
3. Новая широкая tooltip-проекция для quest/creature/recipe/mount и других
   типов должна быть выполнена на candidate-версиях перед публикацией.
4. Для публичного доступа потребуются отдельные письменные grants; текущая
   настройка предназначена для закрытой библиотеки Gildra.

## Правило публикации

Снимок можно считать готовым только после успешных проверок: свежая
проекция, отсутствие unresolved tooltip-токенов в публичном тексте, рабочие
иконки или явный статус `missing`, сохранённое происхождение каждой строки,
проверенный backup/restore и smoke-тесты `/library/**` для EN/RU.
