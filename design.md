# Gildra — правила дизайна

Дата решения: 2026-10-08. Направление бренда: [brand.md](brand.md).
Этот документ заменяет прежнее описание дизайна. Он задаёт целевой вид, а не утверждает, что все страницы уже приведены к нему.

## Два вида страниц

Главная: фон с персонажем, атмосферная сцена и книга. Книга раскрывает оглавление и служит навигацией.
Внутренние страницы: тёмный атлас в стиле текущих «Рейдов» и Mythic+. Светлый книжный разворот не используется для содержимого разделов.
Книга остаётся доступной через «Оглавление» на внутренних страницах.

## Палитра

Значения ниже взяты из существующих CSS атласов. Это исходные значения для будущих общих токенов, а не уже внедрённая тема.

| Назначение | Значение |
| --- | --- |
| Основной фон | `#050607` |
| Светлый текст | `#d9d0c0` |
| Оранжево-янтарный акцент | `#d1a24b` |
| Яркий акцент иконок | `#f0b55a` |
| Тонкая рамка | `rgba(157, 112, 48, .45)` |
| Тёмная поверхность | `rgba(9, 10, 11, .97)` |

При унификации вынести палитру в общий файл темы и использовать семантические CSS-переменные. Не создавать отдельный основной цвет для каждого раздела. Цвета классов, ролей, статусов и иллюстраций остаются смысловыми исключениями.

## Компоновка

Сохранять верхнюю панель Gildra и кнопку оглавления. Под ней — крупный заголовок раздела, короткое пояснение и полезные счётчики. Затем основной контент.
Списки рейдов, боссов и подземелий используют карточки с иллюстрациями. Тир-листы используют читаемые таблицы и фильтры в той же теме. Персонажи используют тёмные панели списка, подключения аккаунта и подробностей героя.

Эталон атласов: контейнер до 1540 px, боковые отступы 26 px на широком экране. На телефоне уменьшать отступы, перестраивать сетку и сохранять доступность действий. Таблицы могут прокручиваться внутри своей области; вся страница не должна иметь горизонтальную прокрутку.

## Текст, изображения и действия

Использовать существующие шрифты и типографику атласов. Декоративное оформление не должно ухудшать чтение таблиц, описаний и фильтров.
Изображения брать из существующих ресурсов проекта с подтверждённым происхождением. Для отсутствующих изображений показывать аккуратное состояние без сломанной картинки.
У каждой кнопки есть действие. Загрузка, пустой результат, ошибка и недоступные данные оформляются явно. Не выдавать фиксированные данные за текущую статистику. Персонажи аккаунта приходят из Battle.net.

## Доступность и движение

Кнопки и ссылки доступны с клавиатуры, фокус виден, иконки имеют подписи там, где без них теряется смысл. Выбор не обозначается только цветом.
Учитывать `prefers-reduced-motion`. Анимация книги и переходов не должна блокировать чтение или оставлять содержимое размытым после загрузки.

## Проверка изменения

Проверять английскую и русскую версии, широкую и мобильную компоновку, клавиатуру, состояния данных и консоль браузера. Скриншоты делать после загрузки шрифтов, изображений и завершения вступительной анимации.
Сборка подтверждает работоспособность кода; скриншоты подтверждают визуальное соответствие.
