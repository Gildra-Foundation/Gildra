# Original raid hub frames

Created 2026-10-25 UTC using the built-in image_gen tool. Five independent original raster generations, one per raid; no borrowed or recolored dungeon frames. These are decorative fantasy interface designs, not game screenshots or boss portraits.

Every source is 1536 × 1024 RGBA. Both the central aperture and the exterior are genuinely transparent. Final assets are 960 × 640 WebP, encoded with sharp quality 88 / alphaQuality 100 / effort 6. Only proportional resize and encoding were applied; generated alpha was preserved. Complete frames remain inside their canvas and are rendered with object-fit: contain.

The corresponding measured inner edges and responsive underlap are in `components/wow/raid/raidHubFrames.ts`. The image window sits behind the frame; each scene alone uses object-fit: cover. Measurements refer to source pixels, not CSS offsets guessed from another frame.
