# Frost login icon ornaments

Four original decorative interface illustrations, generated separately with the
built-in `image_gen` tool on 2026-10-26 with true transparent RGBA backgrounds.
The existing frost-login crest was used only as a palette/craftsmanship reference.
These are not official Blizzard item, spell or ability icons and represent no
game data. Each accompanies a complete HTML text label; image alt text is empty.

- `lock.webp`: silver-steel padlock and glacial blue keyhole surround.
- `equipment.webp`: silver-rimmed dark steel shield with icy shoulders.
- `talents.webp`: dark grimoire, steel clasps and an ice-blue central diamond.
- `combat.webp`: two crossed ice-edged steel blades.

Delivery uses the existing square asset packing recipe: alpha trim,
proportional fit into 140×140, 2 px transparent padding, 144×144 WebP, quality 88,
alpha quality 100. No retouching, recolouring, compositing or background removal.
`manifest.json` records native/final dimensions, hashes, crop and byte counts.

Native PNGs, complete prompts and visual proofs are retained outside `public/`:
`/home/debian/gildra-frost-login-release-20261026/details-r2/asset-sources/`.
The native reference crest is in the parent release's `asset-sources/` folder.
